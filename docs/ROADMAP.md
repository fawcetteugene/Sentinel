# Sentinel AI Development Roadmap

## Milestone 1: Foundation

- Offline-first auth and RBAC
- Core relational tables
- Seed data
- Health checks and root endpoint
- Basic dashboard and navigation shell
- Verification: login, protected routes, root/health endpoints, seeded data

## Milestone 2: Simulation Core

- Simulation engine
- Auto-generated incidents
- Simulated weather
- Traffic and road closure changes
- Resource usage and fuel depletion
- Verification: timed state changes, deterministic behavior, visible live updates

## Milestone 3: Operations Core

- Mission control workflows
- Incident lifecycle management
- Dispatch and assignment tooling
- Map layers and replay timeline
- Verification: mission assignment, incident triage, replay generation, live feed sync

## Milestone 4: Command Oversight

- Admin panel
- System health
- Audit logs
- Global search
- Settings and role controls
- Verification: role restrictions, audit entries, health snapshots

## Milestone 5: Demo Hardening

- UI polish
- Empty states and loading skeletons
- Responsive tuning
- Report exports
- README and screenshots
- Docker and deployment hardening
- Verification: production build, smoke tests, demo walk-through
